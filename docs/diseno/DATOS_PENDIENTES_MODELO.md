# Recursos que requieren definición documental

Autores: Leonel Salva y Luciana Russo.

El paquete final está instalado: dos bocetos, dos lotes, ocho finales y 76 recursos visuales. Este listado no solicita repetir la entrega ni producir imágenes nuevas.

- **1582, alternativa 1, rama 2718, escena base:** el índice la identifica como A/314, pero no asigna un archivo verificable a esa etapa. Confirmar el SHA-256 exacto del archivo adoptado y el documento que acredita la relación, o confirmar que no se conserva. La composición de figuras GL10 sí está vinculada; no se sustituye la base por GL10 ni por el final.
- **1663, alternativa 1, rama 2718, escena base y figuras:** los registros mencionan B1977 y BP, con varias operaciones y sin una imagen única asignada a las etiquetas de interfaz. Confirmar si existe un archivo adoptado por etapa, con SHA-256 y evidencia, o mantener No documentado.
- **Guías interpretativas:** no se identificó una adopción explícita con asociación suficiente para normalizar las guías común/sectoriales del ejemplo. Si corresponde incorporarlas, indicar archivo/hash, boceto, sector, versión, relación derivado_de y etapas que las usaron. Una base, máscara o par de ejemplos ya conservados no se convierte automáticamente en guía.
- **Identidad de referencias:** Día de trabajo / inventario 582 tiene evidencia explícita por hash. Para otras identidades se necesita la misma relación documental; el nombre del archivo no basta. La versión de corpus o el uso en adaptación también requieren evidencia independiente.

En los dos pilotos el acabado separado consta como No aplica. No se solicita una imagen para completar esa etapa. La aplicación conserva los finales y permite consultar los registros, aunque una etapa no pueda conformarse. No se crearon decisiones humanas para completar los ejemplos de los mockups.
